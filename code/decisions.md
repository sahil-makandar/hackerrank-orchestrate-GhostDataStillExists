One line per real decision: date | decision | why.

- 2026-10-24 | Python 3.12, code under `code/`, entry point `code/main.py` | Matches the starter layout and README; Python is installed locally.

- 2026-10-24 | Never use case_id ranges or case-family shortcuts; NOT_APPLICABLE comes only from `request_text` | Contract forbids shortcuts, and the system must generalise.
